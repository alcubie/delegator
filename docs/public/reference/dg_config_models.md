# Alcubi Delegator CLI Reference: dg config models

## dg config models

List the models the default agent offers.

### Synopsis

Start the default agent, list the model IDs it advertises, and stop it. Those IDs are the values that default_model accepts.

```
dg config models [flags]
```

### Examples

```
  dg config models
```
