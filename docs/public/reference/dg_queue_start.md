# Alcubi Delegator CLI Reference: dg queue start

## dg queue start

Start a paused queue.

### Synopsis

Resume a paused queue and start queued tickets until the configured run limits are filled.

```
dg queue start [flags]
```

### Examples

```
  dg queue start
```
