# Alcubi Delegator CLI Reference: dg pause

## dg pause

Pause the queue.

### Synopsis

Pause the queue so no new agent runs start. Runs already in progress are allowed to finish.

```
dg pause [flags]
```

### Examples

```
  dg pause
```
