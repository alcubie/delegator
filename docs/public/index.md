# Alcubi Delegator CLI Reference

Delegator keeps coding-agent work in an ordered queue and isolates each task in
its own Git worktree. `dg` is its command-line interface.

[Browse the complete `dg` command reference](reference/dg.md), or use the
search box to find a command, flag, or setting.

## Common tasks

- Create work with [`dg ticket`](reference/dg_ticket.md).
- Inspect a ticket with [`dg show`](reference/dg_show.md).
- See all queued and completed work with [`dg list`](reference/dg_list.md).
- Continue an agent session with [`dg chat`](reference/dg_chat.md).
- Configure the instance with [`dg config`](reference/dg_config.md).

The command pages are generated from the same Cobra command tree that powers
`dg help`, so command syntax is maintained in one place.
