Changes the requirements:
- follow the UNIX philosophy of doing one thing and doing it very well (avoid scope creep - focus more)
- it also allows flexibility so that users can use it within their existing workflow and it doesn't couple other programs together (ie. it could be used for programmers or something else entirely)
- this is a tool to delegate long-running tasks of various size and complexity for the AI era
- it prevents cognitive overload and assists with coming back to delegated tasks that are now waiting for input so that the human user can reload context extremely quickly and easily
- to avoid overwriting files, delegator only accepts tickets in projects that are under version control
- all work is done in a worktree branch (branches must be in the git repo so they can be opened later after the worktree is deleted)
- tickets are saved as .md files rather than directly in the database.  This allows them to be modified directly by the user if needed and viewed outside of delegator
- the user retains focus by not seeing  all the output generated by AI agents.  They just see the original ticket request.  They have links or info to the variables for the task in case they want to work with those separately such as:
    - worktree directory
    - branch
    - ticket file location
    - AI agent session
- the MCP server allows for ticket management outside of the CLI
- it should be easy to install.  Many command line tools offer an easy way to install.  There should be Linux and Mac versions from the start.  ie. from Tailscale: `curl -fsSL https://tailscale.com/install.sh | sh` or they have Mac versions with a .pkg https://pkgs.tailscale.com/stable/#macos.  Here's another example with flyctl https://fly.io/docs/flyctl/install/ and another https://github.com/anthropics/claude-code
- users should be able to upgrade - this makes having a database tricky as we need to have migrations.  The schemas also need to be fixed.  ie. if a person uninstalls a version and then installs a newer version, their old files may not load correctly
